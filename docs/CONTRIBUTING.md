# 開発時の規則

- C++17 と Windows x64 の MSVC ツールチェーンを使用します。
- `if` / `else` / `for` / `while` 等の本体には、一文でも中括弧を付けます。
- 一行に複数の処理を詰めず、所有権・座標系・実行スレッドが分かる名前とコメントを使います。
- `scripts/Format-Source.ps1` で整形し、`scripts/Test-SourceStyle.ps1` で整形・中括弧・PowerShell 構文を確認します。
- ビルド後は変更に関連する回帰試験を実行します。Explorer を操作する試験では既存パッチを解除してから実行し、結果と復元を確認します。
- EXE、DLL、画像、検証結果等のバイナリ／生成物はコミットしません。検証画像は `tests/New-TestImage.ps1` から生成します。
- 読み込み中の DLL を上書きせず、新しいビルド先を使用します。

Git の作成者情報には各開発者の設定を使用します。Codex を使用したコミットはメッセージに次のトレーラーを付けます。

```text
Assisted-by: Codex (OpenAI)
```
